Opis książki

Dodaj książkę na półkę

1. Pobierz okładkę i szczegóły po ISBN

Wpisz 10 lub 13-cyfrowy numer ISBN lub zeskanuj kod kreskowy aparatem.

Skieruj aparat na kod kreskowy książki (EAN / ISBN-13)

2. Nośnik, status, ocena i miejsce zakupu

3. Dane książki, gatunek i okładka (uzupełniane automatycznie po ISBN)

Brak okładki Pobierz po ISBN lub wgraj obraz

Baza JSON i synchronizacja z GitHubem

Połącz aplikację ze swoim darmowym repozytorium na GitHubie. Każde dodanie lub ocena książki automatycznie zaktualizuje plik data/books.json na Twoim koncie GitHub.

Token z uprawnieniem Contents: Read and write dla wybranego repozytorium. Nigdy nie trafia do pliku JSON.

Wszystkie Twoje książki są przechowywane w czytelnej strukturze JSON. Możesz w każdej chwili pobrać plik books.json lub wczytać go z dysku.

1

Utwórz darmowe repozytorium na GitHubie

Zaloguj się na github.com, kliknij New repository, nazwij je np. moja-biblioteczka i wrzuć do niego pliki tej aplikacji (index.html, styles.css, app.js, manifest.json, sw.js, data/books.json, icons/).

2

Włącz darmowy hosting GitHub Pages

W repozytorium wejdź w Settings → Pages, w sekcji Build and deployment wybierz gałąź main i kliknij Save. Twoja biblioteczka będzie dostępna pod adresem https://paqs-89.github.io/moja-biblioteczka/ (na iPhonie kliknij „Udostępnij → Dodaj do ekranu początkowego”).

3

Wygeneruj darmowy token do automatycznego zapisu JSON

Na GitHubie wejdź w Settings (Twojego konta) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token:

  • Repository access: wybierz Only select repositories → wskaż moja-biblioteczka
  • Permissions → Repository permissions → Contents: ustaw na Read and write
  • Skopiuj wygenerowany token i wklej go w zakładce Konto GitHub powyżej.
